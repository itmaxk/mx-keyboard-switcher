# Контекст MX Keyboard Switcher

Офлайн-приложение на Rust для исправления текста, набранного в неверной
раскладке. Текущая пара языков — русский/английский. Главный приоритет
детекции: ложное исправление хуже пропущенного. Физические клавиши в буфере
позволяют преобразовывать слово независимо от активной раскладки.

## Границы компонентов

| Компонент | Ответственность |
|---|---|
| mxks-core | Буфер клавиш, таблицы раскладок, словари, детекция, конвертация, конфигурационные типы, счётчики использования |
| mxks-platform | Захват и инъекция событий, смена раскладки, фокус, перехват и overlay для X11/Windows/macOS |
| mxks-app | Сборка компонентов, Engine, Corrector, трей, файловая конфигурация, автозапуск и диагностические логи |

Точка входа — `crates/mxks-app/src/main.rs`. Поток захвата отправляет события
движку по каналу; команды трея приходят отдельно. Движок хранит состояние
слова и решает, когда корректировать и показывать подсказку. Corrector
выполняет коррекцию через платформенные интерфейсы.

## Термины

- **Конвертация** — преобразование набранного слова по таблице другой раскладки.
- **Автокоррекция** — применение конвертации по решению детектора.
- **Автодополнение** — предложение кандидата по префиксу; это отдельное поведение.
- **Счётчик использования** — обучение кандидатов после принятия показанного слова;
  локальное состояние и переносимый экспорт имеют разные файлы.
- **Фокус** — приложение/поле ввода, изменение которого влияет на состояние буфера.
- **Инъекция** — отправка синтетических нажатий. В разработке требует изоляции.

## Платформы и проверка

Linux использует X11. Windows и macOS имеют собственные backend;
наличие реализации и прохождение CI не заменяют ручной проверки на устройстве.
Ограничения Wayland описаны в README. Приложение не должно требовать сеть.
